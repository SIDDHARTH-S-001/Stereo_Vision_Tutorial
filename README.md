# Stereo Vision Tutorial

## Project Description
This project provides a hands-on tutorial for building a **Stereo Vision** setup using Logitech C270 webcams. It is aimed at hobbyists, students, and developers interested in learning stereo vision concepts and experimenting with various algorithms.

## Key Features
- 📷 **Stereo Vision Algorithms**: Explore a variety of stereo vision techniques and depth map generation methods.
- 🛠 **3D Printable Mounts**: CAD files for webcam mounts are provided in multiple formats — `.F3D`, `.STEP`, `.OBJ`, and `.STL`.
- 🧩 **Customizable Designs**: CAD files were adapted and tweaked from [Reference [1]](#references).

## Hardware Requirements
- Two webcams (preferably **Logitech C270** for better compatibility and performance).
- A mounting solution (CAD files included) to align the webcams securely for stereo imaging.

## Software Requirements
- **Python 3.9+**
- **OpenCV 4.x**

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/stereo-vision-c270.git
   cd stereo-vision-c270
   ```
2. Install the required Python packages:
   ```bash
   pip install opencv-python
   ```

3. Follow the tutorial notebooks/scripts to start capturing stereo images and generating depth maps.
